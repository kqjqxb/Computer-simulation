# Комп'ютерний практикум №5

Формалізація дискретно-подійних систем стохастичною мережею Петрі.

| Файл | Призначення |
|---|---|
| `fun_rand.py` | генератори випадкових величин |
| `petri.py` | стохастична часова мережа Петрі: пріоритети, ймовірності, багатоканальні переходи, інформаційні дуги, кратності дуг, статистика |
| `runner.py` | серії прогонів і довірчі інтервали |
| `task1_conveyor.py` | завдання 1: конвеєрна система з п'ятьма пристроями |
| `task2_fms.py` | завдання 2: роботизована гнучка виробнича система, два варіанти закріплення роботів |
| `task3_minibus.py` | завдання 3: мікроавтобуси на приміському маршруті |
| `task4_inventory.py` | завдання 4: управління запасами холодильників |
| `plots.py` | графіки результатів |
| `results/net*.json` | опис мереж (позиції, переходи, дуги) для реалізації в ЛР6–ЛР7 |
| `results/` | вивід програм, результати, графіки |
| `ІП-33_Ломакін_ЛР5.pdf` | звіт |

```bash
cd lab5
../.venv/bin/python task1_conveyor.py > results/task1_output.txt   # ~1 хв
../.venv/bin/python task2_fms.py > results/task2_output.txt         # ~1,5 хв
../.venv/bin/python task3_minibus.py > results/task3_output.txt     # ~1 хв
../.venv/bin/python task4_inventory.py > results/task4_output.txt   # ~1 хв
../.venv/bin/python plots.py
```
