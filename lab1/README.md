# Комп'ютерний практикум №1

Перевірка генератора випадкових чисел на відповідність закону розподілу.

| Файл | Призначення |
|---|---|
| `stats_utils.py` | критерій χ², перевірка кореляції, критерій серій |
| `task1_generators.py` | завдання 1: експоненційний генератор (метод оберненої функції) і конгруентний генератор |
| `measure_sorting.py` | завдання 2: вимірювання часу сортування 1 000 000 об'єктів → `data/sort_times.csv` |
| `task2_analysis.py` | завдання 2: ідентифікація закону розподілу та імітаційні генератори затримки |
| `results/` | графіки та вивід програм |
| `ІП-33_Ломакін_ЛР1.pdf` | звіт |

```bash
cd lab1
../.venv/bin/python task1_generators.py
../.venv/bin/python measure_sorting.py     # ~10 хв, перезаписує data/sort_times.csv
../.venv/bin/python task2_analysis.py
```
