# Комп'ютерний практикум №3

Побудова імітаційної моделі системи з використанням формалізму моделі масового обслуговування.

| Файл | Призначення |
|---|---|
| `fun_rand.py` | генератори випадкових величин |
| `item.py` | вимога з типом, моментом створення та атрибутами |
| `element.py` | базовий `Element` і `Route`: маршрут за ймовірністю, пріоритетом, умовою або правилом |
| `elements.py` | `Create`, `Process` (багатоканальний, пріоритетна черга), `Dispose` |
| `model.py` | `Model`: принцип найближчої події, обробники подій, розгін |
| `queueing_theory.py` | формули M/M/c/K, Ерланга B, Кобхема |
| `runner.py` | серії прогонів і довірчі інтервали |
| `task1_universal.py` | завдання 1: перевірка універсального алгоритму |
| `task2_bank.py` | завдання 2: банк для автомобілістів |
| `task3_hospital.py` | завдання 3: приймання хворих у лікарню |
| `results/` | вивід програм |
| `ІП-33_Ломакін_ЛР3.pdf` | звіт |
